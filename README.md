# Irpin-WebGIS
----------------------------------------
## Про проєкт
Інтерактивна вебкарта гідрографічної мережі басейну річки Ірпінь. Проєкт призначений для візуалізації основного русла річки та мережі малих водотоків.
Карта створена за допомогою бібліотеки Leaflet, просторових даних GeoJSON та картографічної підкладки OpenStreetMap. Вебсторінка опублікована за допомогою GitHub Pages.

## Перегляд карти
Для перегляду карти достатньо перейти за посиланням: https://6246026-arch.github.io/Irpin-WebGIS/ . 
Після завантаження можна переміщуватися картою, змінювати масштаб і керувати відображенням тематичних шарів за допомогою панелі у верхньому правому куті.

## Функціональні можливості
-Відображення основного русла річки Ірпінь.
-Відображення мережі малих водотоків.
-Роздільна стилізація гідрографічних об'єктів.
-Увімкнення та вимкнення тематичних шарів.
-Масштабування та переміщення картою.
-Перегляд просторових об'єктів на підкладці OpenStreetMap.

## Структура проєкту
-index.html — основна сторінка інтерактивної карти.
-Irpine_River.json — просторові дані основного русла річки Ірпінь.
-Irpin_Streams.json — просторові дані мережі малих водотоків.
